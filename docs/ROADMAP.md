# 로드맵

각 단계는 **앞 단계가 며칠 문제없이 돌아간 뒤** 열고, 단계마다 SECURITY.md 의 해당 항목을 먼저 구현한다.

| 단계 | 내용 | 위험 | 상태 |
|---|---|---|---|
| 1 | 알림 전용: 작업 폴더·뉴스 키워드 → 텔레그램 | 거의 없음 | **현재** |
| 1.5 | 출근 시 인사 + 어제 작업 안내 (Windows 로그온 트리거) | 낮음 | 예정 |
| 2 | LLM 판단: 요약, 중요도, 이동 일정 + 날씨/경로 조합 | 중간 (비용·일관성) | 예정 |
| 3 | 수신: 버튼 응답, `chat_id` 허용 목록, 승인 흐름 | 높음 (명령 채널) | 예정 |
| 4 | 메일: 읽기 전용 → 요청 메일 알림 → 답장 초안 → 승인 후 발송 | 높음 | 예정 |
| 5 | 코드 업데이트 에이전트: 변경 감지 → 브랜치 + PR, 반영은 사람 | 높음 | 예정 |

## 단계 1 완료 기준
- [ ] 실제 텔레그램으로 알림 1건 수신
- [ ] 같은 항목이 두 번 오지 않음 (재실행으로 확인)
- [ ] 조용한 시간에 알림이 오지 않고 아침에 몰려서 옴
- [ ] 3일 연속 작업 스케줄러 자동 실행 성공 (`data/aide.log` 확인)
